# API REST con Express y Prisma

Este proyecto es una práctica donde hice una **API REST** usando **Express** y **Prisma**, conectada a una base de datos en **Supabase**.  
La API permite manejar **usuarios** y **tareas**, con operaciones como crear, ver, editar y eliminar datos.


## Pasos que hice

1. Inicié el proyecto con **Express** y armé la estructura base de carpetas.  
2. Instalé **Prisma** y lo conecté con mi base de datos de **Supabase**.  
3. Creé el **schema** con los modelos `User` y `Task`, e hice la **migración** para generar las tablas.  
4. Hice los **controladores** y **rutas** para los usuarios.  
5. Luego hice lo mismo para las tareas.  
6. Probé todos los endpoints en **Insomnia** y revisé que funcionaran bien.  

---

## Tecnologías que usé

- Node.js  
- Express  
- Prisma ORM  
- Supabase (PostgreSQL)  
- Insomnia  


## Resultado

Logré crear una API sencilla que se conecta a una base de datos y permite manejar información básica de usuarios y tareas.  
Fue una buena práctica para entender cómo funcionan **Express** y **Prisma** juntos.
